# Sample Security FAQ

This is fictional sample guidance for exercising document search and source
citation. Follow your real organization's approved security policies instead.

## Reporting suspicious messages

Do not open unexpected attachments or enter credentials through links in
suspicious messages. Report the message to the security team using the
organization's approved reporting channel.

## Passwords and multi-factor authentication

Use a unique password for each work account and store it in an approved password
manager. Enable multi-factor authentication whenever the service supports it.

## Lost devices

Report a lost or stolen work device to the IT help desk as soon as possible.
Do not attempt to recover a device by confronting anyone or entering an unsafe
location.
